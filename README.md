Generate and read QR codes entirely on your machine. No network access, works offline.

## Installation

```bash
pip install git+https://github.com/yu9824/qrlocal.git
```

## Directory layout

| Directory | Purpose |

| `src/qrlocal/` | Package source |
| `tests/` | pytest tests |
| `docs_src/` | Sphinx source |
