qrlocal package#

Generate and read QR codes locally, without network access.

Examples

>>> import qrlocal
>>> qrlocal.save_qr("https://example.com", "example.png")
>>> print(qrlocal.render_terminal("hello"))
>>> qrlocal.decode_image("example.png")  # needs qrlocal[camera]
['https://example.com']
qrlocal.decode_image(path: str | PathLike[str]) → list[str]#

Read the QR codes in an image file.

Parameters:

path (str or os.PathLike) – An image OpenCV can read, such as PNG, JPEG, or BMP.

Returns:

The text of each code found, in no particular order. Empty if there is none.

Return type:

list of str

Raises:

  • ImportError – If OpenCV is not installed.

  • FileNotFoundError – If path does not exist.

  • ValueError – If the file is not an image OpenCV can read.

Notes

The text comes from outside; do not open or run it without checking.

qrlocal.escape_control_chars(text: str) → str#

Escape characters that could take over a terminal.

Text read from a QR code comes from anyone. Printed as is, an escape sequence in it could change the terminal (colors, title, cursor, or worse on some terminals), and a carriage return or bidirectional control could make it look like something else. This replaces control characters other than \n and \t, and bidirectional controls, with escapes such as \x1b.

Parameters:

text (str) – The text to make printable.

Returns:

The text with the characters escaped.

Return type:

str

Examples

>>> escape_control_chars("ok\x1b[2J")
'ok\\x1b[2J'
qrlocal.make_qr(text: str, *, error: Literal['L', 'M', 'Q', 'H'] = 'M') → QRCode#

Encode text into a QR code.

Non-ASCII text is stored as UTF-8 in byte mode without an ECI header, which phones and OpenCV read as is.

Parameters:

  • text (str) – The text to encode. Must not be empty.

  • error ({"L", "M", "Q", "H"}, default "M") – Error correction level. A higher level survives more damage but holds less text.

Returns:

The QR code.

Return type:

segno.QRCode

Raises:

ValueError – If text is empty or too long, or error is unknown.

qrlocal.render_terminal(text: str, *, error: Literal['L', 'M', 'Q', 'H'] = 'M', border: int = 4, invert: bool = False) → str#

Draw text as a QR code with Unicode half blocks.

Two rows of modules fit in one line. By default light modules are drawn with blocks, which suits a light-on-dark terminal; pass invert=True for a dark-on-light one.

Parameters:

  • text (str) – The text to encode.

  • error ({"L", "M", "Q", "H"}, default "M") – Error correction level.

  • border (int, default 4) – Width of the quiet zone, in modules.

  • invert (bool, default False) – Draw dark modules with blocks instead of light ones.

Returns:

The drawing, one line per two rows of modules, ending in a newline.

Return type:

str

qrlocal.save_qr(text: str, path: str | PathLike[str], *, scale: int = 10, border: int = 4, error: Literal['L', 'M', 'Q', 'H'] = 'M', overwrite: bool = False) → Path#

Write text as a QR code image.

The format follows the extension of path: .png or .svg. A new file is readable by its owner only, since the image holds the text.

Parameters:

  • text (str) – The text to encode.

  • path (str or os.PathLike) – Where to write the image.

  • scale (int, default 10) – Size of one module, in pixels (PNG) or user units (SVG).

  • border (int, default 4) – Width of the quiet zone around the code, in modules. Readers need at least 4 to find the code reliably.

  • error ({"L", "M", "Q", "H"}, default "M") – Error correction level.

  • overwrite (bool, default False) – Replace path if it already exists.

Returns:

The path written to.

Return type:

pathlib.Path

Raises:

  • ValueError – If the extension, scale, border, text, or error is invalid.

  • FileExistsError – If path exists and overwrite is False.

qrlocal.scan_camera(*, device: int = 0, timeout: float | None = None, preview: bool = True) → str | None#

Read a QR code with a camera.

Frames are processed in memory only and never written anywhere. The camera and the window are released when this returns, also on errors and Ctrl+C.

Parameters:

  • device (int, default 0) – Index of the camera.

  • timeout (float, optional) – Give up after this many seconds. Wait forever by default.

  • preview (bool, default True) – Show what the camera sees in a window. Press q or Esc there, or close it, to stop.

Returns:

The text of the first code read, or None if the user stopped.

Return type:

str or None

Raises:

  • ImportError – If OpenCV is not installed.

  • ValueError – If timeout is not positive.

  • RuntimeError – If the camera or the preview window cannot be opened, or the camera stops sending frames.

  • TimeoutError – If no code is read within timeout seconds.

Notes

The text comes from outside; do not open or run it without checking.
